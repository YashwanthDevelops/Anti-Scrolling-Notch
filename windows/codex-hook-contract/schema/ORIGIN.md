# Pinned Codex hook schemas

The four input schemas in `rust-v0.157.1/` are generated by OpenAI Codex and are copied from the exact source revision corresponding to the installed `codex-cli 0.157.1` runtime recorded in the accepted loopback evidence. Their source, version, source commit, Git blob IDs, SHA-256 checksums, and the complete schema filename inventory are recorded in `release-0.157.1-manifest.json`.

The generated Rust type intentionally includes only the event discriminators from those four runtime-observed schemas. The adapter does not deserialize their other fields. The remaining release schemas are listed for compatibility reference, but their event types are not generated into or accepted by the adapter until runtime delivery is captured and accepted.

The copied schemas are distributed under Apache-2.0; the corresponding upstream `LICENSE` and `NOTICE` files are included beside them, with their source blob IDs recorded in the manifest. Upstream source: <https://github.com/openai/codex/tree/rust-v0.157.1/codex-rs/hooks/schema/generated>.
